# Security Policy

## Supported versions

Security fixes are released for the latest minor version.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(**Security → Report a vulnerability** on the repository) or email **info@furnas.technology**.

You should receive a response within a few working days. Note that the timeline renders tooltips from strings as text,
never HTML; custom `HTMLElement` tooltips are the caller's responsibility.
