# Demo data

| File                       | Source                                                                                                                                                                                                                                                                                                                                                                                                     | Licence                              |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| `atlantic-hurricanes.json` | NOAA National Hurricane Center, [HURDAT2 Atlantic best-track data](https://www.nhc.noaa.gov/data/#hurdat) (file `hurdat2-1851-2025-02272026.txt`), seasons 2015–2025. Per storm: tropical-phase dates, peak Saffir–Simpson category from maximum sustained wind, minimum pressure, accumulated cyclone energy (ACE, 10⁻⁴ kt² summed over 6-hourly synoptic records with winds ≥ 34 kt) and landfall count. | Public domain (U.S. Government work) |
| `commerce-contracts.json`  | [USAspending.gov](https://www.usaspending.gov/) award search API: the largest U.S. Department of Commerce contracts (award types A–D) active in fiscal year 2025, filtered to a period of performance within 2022–2030 and at most six years. Fields: award ID, sub-agency (abbreviated), recipient, period of performance, award amount, contract type and a shortened description.                       | Public domain (U.S. Government work) |
| `danceCompetitions.ts`     | Synthetic generator — fictional competitions, venues and figures.                                                                                                                                                                                                                                                                                                                                          | MIT (this repository)                |

The JSON files are static snapshots; they are not fetched at runtime.
